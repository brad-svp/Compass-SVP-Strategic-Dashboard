# SVP community photographs

These photographs were selected from the public SVP Photo Library at the
product owner's request for the internal home page. They are curated snapshots,
not a live synchronization with the photo library.

| File | Library program | Original source |
| --- | --- | --- |
| `100x.webp` | 100x | https://photos.svpsacramento.org/api/photos/1OLUK8Yk0SqLy3js1JC4_PNDTySX2zxeo/view |
| `fast-pitch.webp` | Fast Pitch | https://photos.svpsacramento.org/api/photos/1VR_rGzAHTeJpApyvEpYWEfwhDZAwlHUT/view |
| `think-tank.webp` | Think Tanks | https://photos.svpsacramento.org/api/photos/1b4E41i62UZb-ivkCoXI9SaaS5bay0CWk/view |

The web copies are limited to 1,200 pixels wide, converted to WebP, and stripped
of camera/EXIF metadata. Original-resolution files are not included in the app.
Captions identify programs, not individual people or unverified event dates.
